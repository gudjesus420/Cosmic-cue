
# Cosmic Stoner Billiards

**Cosmic Stoner Billiards** is a web-based browser game built with HTML, CSS, and JavaScript. You can play directly in your browser once hosted on GitHub Pages.

## How to Play
Simply open the game in your browser after uploading to GitHub Pages.

## GitHub Pages Deployment
To publish this game:

1. Create a new repository (e.g., `cosmic-stoner-billiards`) on your GitHub account.
2. Upload all the files from this project (not the zip file itself, but its contents).
3. Go to your repo's **Settings > Pages**.
4. Under **Source**, choose the `main` branch and `/ (root)` folder.
5. Click save. Your game will be live at:

```
https://<your-github-username>.github.io/cosmic-stoner-billiards/
```

In your case:
```
https://gudjesus420.github.io/cosmic-stoner-billiards/
```

Enjoy!
